# Security Policy

## Supported Versions

Security updates and critical patches are actively applied to the following release tracks:

| Version | Supported          |
| :---    | :---               |
| `main`  | Yes                |
| `< 1.0` | No                 |

---

## Reporting a Vulnerability

The Odyssey maintainers take security and data integrity seriously. If you discover a potential vulnerability in our authentication, payment QR dispatch, file ingestion, or database pipeline, please report it responsibly.

### How to Report
- **Email**: Send vulnerability reports directly to `mohammedsahil0003@gmail.com`.
- **Subject**: `[SECURITY VULNERABILITY] Odyssey - <Brief Summary>`
- **Content**: Please include:
  1. Description of the vulnerability and its potential impact.
  2. Step-by-step reproduction instructions or proof-of-concept script.
  3. Affected component (`frontend/`, `backend/`, dependencies).
  4. Suggested remediation if available.

### Disclosure Policy
- Please **do not** report security vulnerabilities through public GitHub issues or discussions.
- We will acknowledge receipt of your report within **48 hours**.
- We will provide a timeline for validation and release of a patch.
- We kindly ask that you keep the details confidential until a fix has been published.
